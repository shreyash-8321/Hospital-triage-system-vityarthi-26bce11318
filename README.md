## Files in This Project
* `src/main.py` - Main entry point with the menu
* `src/file_handler.py` - Handles saving/loading JSON data
* `src/patient_ops.py` - Logic for adding and managing patients
* `src/triage.py` - Queue sorting algorithm
* `src/prescribe.py` - Medicine suggestion logic
* `src/medicine_data.json` - Contains symptom and medicine information
* `src/patient_records.json` - Stores the patient records
* `statement.md` - Problem statement and project scope

## How to Run
1. Make sure Python is installed.
2. Open the project folder in VS Code or PyCharm.
3. Open the terminal.
4. Navigate into the source folder by typing: `cd src`
5. Run the program by typing: `python main.py`
6. Select the options from the interactive menu.
